OAG provides comprehensive aviation data and analytics, delivering real‑time flight schedules, status, fares, historical records, and passenger booking information. Their platform powers airlines, airports, travel tech, and finance firms with APIs that enable data‑driven decisions across the global travel ecosystem.

**Areas:** Company · Aviation · Data · Analytics · Travel

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OAG: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
