# OAG Developer Portal

> OAG is the world's leading provider of aviation data and analytics. The OAG Developer Portal is a self-service platform for developers to discover, trial, and integrate OAG aviation data APIs.

## APIs and trials

- [Flight Info](https://developers.oag.com/apis/flight-info-v2): Access flight schedules and status per individual flight, including on-time performance indicators and diversion and recovery flight information. Enrich further with optional predicted and actual seat data, all returned in a single API call. Tags: schedules, status, real-time, seats
- [Flight Info Alerts](https://developers.oag.com/apis/flight-info-alerts-v1): React to flight changes the moment they happen. Receive real-time notifications for schedule and status updates, including optional seat data, delivered via HTTP push or pulled from Azure Event Hubs. Tags: real-time, notifications, events, schedules, status
- [Flight Info Alerts Trial](https://developers.oag.com/apis/flight-info-alerts-v1): Try Flight Info Alerts free for 28 days with up to 10 active alerts created. Receive real-time notifications whenever flight schedules or status change, delivered via HTTP push or pulled from Azure Event Hubs. Excludes Global Alerts. Tags: real-time, notifications, events, schedules, status
- [Schedules](https://developers.oag.com/apis/schedules): Access flight schedules at an effective view, returning date ranges and operating days rather than individual flight instances. Enrich responses with optional seat capacity by cabin class. Tags: schedules, planning, historical
- [Flight Info Connections](https://developers.oag.com/apis/flight-info-connections-v1): Access weekly-updated global passenger and cargo connection data, built on OAG schedules and industry-compliant Minimum Connecting Times (MCTs). Tags: connections, MCT, cargo
- [Master Data](https://developers.oag.com/apis/locations-v1): Access reference data for carriers, locations, and equipment across IATA, ICAO, and FAA standards. Includes carrier names and alliance membership, airport codes and time zones, aircraft types, and more. Tags: airports, airlines, cities, time zones, coordinates
